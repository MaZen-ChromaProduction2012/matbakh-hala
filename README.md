# منصة مطبخ حلويات حلا (Hala Sweets) — نسخة الملفات والصفحات المنفصلة 🌾🧁

تم بناء وتقسيم المشروع بالكامل بحيث يكون **بدون أي نوافذ منبثقة (No Pop-ups)** وبملفات مستقلة ومنظمة:

## 📂 هيكل الملفات المنفصلة في المشروع
- `index.html`: هيكل صفحات الموقع المستقلة (الرئيسية والمنيو، صفحة تفاصيل المنتج، صفحة سلة المشتريات، صفحة إتمام الطلب والدفع، صفحة الفاتورة، صفحة خبير السعرات الذكي، صفحة إضافة التقييمات، وصفحات الإدارة).
- `style.css`: ملف التنسيقات والألوان والمقاسات المتجاوبة (`Responsive CSS`) لجميع الأجهزة.
- `app.js`: الكود البرمجي التفاعلي ونظام التنقل بين الصفحات المستقلة والحماية الأمنية (`XSS Protection`).
- `config.js`: إعدادات المتجر وأرقام الواتساب وطرق الدفع.
- `chatbot_and_payment_engine.js`: محرك خبير السعرات الذكي وبوابة الدفع.
- `admin_analytics_engine.js`: محرك تحليلات المبيعات للوحة الإدارة.
- `README_دليل_التشغيل.txt`: دليل التشغيل السريع.
