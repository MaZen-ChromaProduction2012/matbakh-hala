# منصة مطبخ حلويات حلا (Hala Sweets) 🌾🧁

منصة الويب التفاعلية المتكاملة لمطبخ **حلويات حلا** (`@Matbakh_Hala`) — حلو، حادق، ومخبوزات بيتي بالدقيق العادي والحبة الكاملة.

## محتويات المشروع
- `index.html`: تطبيق الويب المتكامل (Single-Page Application) جاهز للنشر الفوري على GitHub Pages أو Netlify أو Vercel، ويضم:
  - المنيو الرسمي المعتمد بالكامل (39 صنفاً موزعة على 8 أقسام: كب كيك، البراونيز، أمريكان كوكيز، كب السعادة، المخبوزات، إنجلش كيك 14 قطعة، قشطوطة، والسينابون).
  - قوائم اختيار النكهة (شوكولاتة / فانيليا / مشكل) والصوص المفضل داخل بطاقة المنتج.
  - سلة المشتريات الذكية بحساب السعرات التلقائي وإرسال الفاتورة مباشرة إلى واتساب.
  - المساعد الذكي لحساب السعرات والأسعار (`HalaCalorieBot`).
  - لوحة تحكم الإدارة الآمنة (`Admin Dashboard`) مع تحليلات المبيعات بالذكاء الاصطناعي.
  - حماية أمنية ضد ثغرات `XSS` وتخمين رمز المرور، وتصميم متجاوب (`Responsive`) لجميع مقاسات الشاشات.
- `config.js`: ملف الإعدادات والبيانات الأساسية.
- `chatbot_and_payment_engine.js`: محرك المساعد الذكي وبوابة الدفع.
- `admin_analytics_engine.js`: محرك تحليلات المبيعات ومؤشرات الأداء (KPIs).
- `README_دليل_التشغيل.txt`: دليل التشغيل والنشر السريع.

## خطوات الرفع على GitHub Pages
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub.
2. فك ضغط الملف المضغوط وارفع الملفات (`index.html` وباقي الملفات) إلى المستودع.
3. من إعدادات المستودع (**Settings** > **Pages**)، اختر الفرع الرئيسي (`main`) ثم اضغط **Save** ليصبح الموقع متاحاً أونلاين فوراً.
